# 1. ClassAndNotes
2. A website where you are able to view your class schedule, see when assignments are due, able to send reminders, and note taking. This is a good tool in my opinion because I like to be organized and have everything in one place. 

3. The target users are college students who want a simple way to mange their classes, assignments, notes, and schedule. This app is designed for indiviudal use, but it can also be useful for a small group of students. 

4. Core Features:
    - users can create academic years, and semsesters (fall, spring, summer), and organize their courses by semester
    - users can add and manage their classes, including instructor, location, and meeting times.
    - Users can create assignments, set due dates and prorities, and track their status (not stated, in progress, completed)
    - users can create and organize notes by course topic, use formatting(headings, bold, lists), add tags, and search their notes.
    - Users can view their class schedule in a weekly timetable, including location and time.

5. the scope of my project is that i believe that is project is good for a 8 week timeline because it is focused and has a clear purpose without it being too complex.
