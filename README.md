# 1. ClassAndNotes
2. A website where you are able to view your class schedule, see when assignments are due, able to send reminders, SMS messages to repeat your notes, play games for memory, and note taking. This is a good tool in my opinion because I like to be organized, have everything in one place,and to have fun.  To explain the SMS message feature on this website, it will take a chunk out of your notes and send them right to your phone to help retain information on the go. Viewing your notes on the go without going through the extra hassle. For games, It is easier for me to retain information when I am having fun. Games like flashcards or a memory card game helps me retain information. Especically if when I am earning in game currency to use to buy decorations for my profile to show off to my friends. 

3. The target users are college students who want a simple way to mangae their classes, assignments, notes, fun, and schedule. This app is designed for indiviudal use, but it can also be useful for a small group of students. 

4. Core Features:
    - users can create academic years, and semsesters (fall, spring, summer), and organize their courses by semester
    - users can add and manage their classes, including instructor, location, and meeting times.
    - Users can create assignments, set due dates and prorities, and track their status (not stated, in progress, completed)
    - users can create and organize notes by course topic, use formatting(headings, bold, lists), add tags, and search their notes.
    - Users can view their class schedule in a weekly timetable, including location and time.
    - Sign up for SMS notifications for the system to send random or specific chunks of your notes to your phone
    - Fun games to help you study:
            * Flashcards
            * Memory card matching
        With the games you are able to earn currency within the webiste. With the currency, you can use your winnings to buy cosmetics for your profile to show off to your friends. 

5. the scope of my project is that i believe that is project is good for a 8 week timeline because it is focused and has a clear purpose without it being too complex.
